# my.gov tracker - Windows App

Это полностью автономное Windows приложение для отслеживания заявок my.gov.uz

## 🎯 Возможности

✅ Работает без интернета (если данные уже загружены)
✅ Полная функциональность веб-приложения в одном .exe файле
✅ Автоматический запуск сервера при открытии
✅ Тёмная тема
✅ Управление проектами
✅ Загрузка и просмотр PDF
✅ Проверка статуса заявок

## 📦 Сборка Windows приложения

### Требования
- Node.js v18+
- npm

### Шаги сборки

#### 1️⃣ Подготовка
```bash
cd D:\utkirov\work\2026\AI\crm-invoices
npm install
```

#### 2️⃣ Сборка для разработки
```bash
npm run build
npm run electron-dev
```

#### 3️⃣ Сборка готового приложения
```bash
npm run build
npm run electron-build-exe
```

Это создаст файлы в папке `dist/`:
- `my.gov tracker-1.0.0.exe` - Установщик
- `my.gov tracker-1.0.0.exe` - Портативная версия (просто запустить)

## 🚀 Использование

### Первый запуск
1. Двойной клик по `.exe` файлу
2. Приложение автоматически запустит встроенный сервер
3. Откроется окно с приложением
4. Введите PIN: `1234`

### После запуска
- Всё работает как веб-приложение, но локально
- Сервер запускается автоматически
- Закрытие окна закрывает сервер

## 🔧 Конфигурация

Приложение использует переменные из `.env.local`:

```
SUPABASE_URL=...
SUPABASE_SERVICE_ROLE_KEY=...
APP_PIN=1234
```

Убедитесь, что `.env.local` находится в корневой папке перед сборкой!

## 🐛 Troubleshooting

**Приложение не запускается:**
- Проверьте, не занят ли порт 3000: `netstat -ano | findstr :3000`
- Переустановите зависимости: `npm install`

**Ошибка "Cannot find module":**
- Удалите `node_modules` и `package-lock.json`
- Запустите `npm install` заново

**Сервер не отвечает:**
- Проверьте .env.local с правильными переменными
- Убедитесь, что Supabase доступна
